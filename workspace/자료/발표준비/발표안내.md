누가 어떤 상황에서 도움을 받는지 설명하는 데 초점을 맞춥니다.

3. 공식 자료에서 확인한 내용과 자신의 해석
4. 기존 흐름에서 개선하고 싶은 지점과 제안 이유

## 자료를 정리할 때

서비스 설명에는 공개 공식자료를 최소 두 개 사용합니다.

직접 사용하지 않은 기능은 사용 후기처럼 표현하지 않습니다.
구현하지 않은 개선안은 제안 단계라고 밝히면 됩니다.
