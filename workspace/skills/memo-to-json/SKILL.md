# 메모 사진 정리

사용자가 제공한 메모 사진을 읽고 다음 항목으로 정리한다.

- 메모 날짜
- 끝낸 일
- 남은 일
- 변경한 내용
- 확인할 질문

매번 같은 항목 이름을 사용하는 JSON으로 출력한다.

## 읽는 방법

- 취소선, X 표시, 밑줄, 화살표, 체크표시를 **문맥과 함께** 읽는다.
- 취소한 내용과 변경 후(새로 적은) 내용을 구분한다. 취소된 것은 결과에 넣지 않고,
  변경 과정을 남겨야 하면 `변경한 내용`에 "A → B" 형태로 적는다.
- 읽기 어렵거나 의미가 애매한 부분은 추측하지 말고 `확인할 질문`에 남긴다.

## 출력 스키마 (고정)

```json
{
  "메모 날짜": "YYYY-MM-DD 또는 null",
  "끝낸 일": ["문자열", "..."],
  "남은 일": ["문자열", "..."],
  "변경한 내용": ["문자열", "..."],
  "확인할 질문": ["문자열", "..."]
}
```

- `메모 날짜`는 `YYYY-MM-DD` 문자열 또는 `null`.
- 나머지 네 항목은 **문자열 목록**. 비어 있으면 `[]`.
- 항목을 빼거나 더하지 않는다. 다섯 항목 이름을 그대로 쓴다.

## 실행 절차

경로는 모두 작업 폴더(`workspace/`) 기준이다.

1. **AI가 사진을 읽는다.** 위 "읽는 방법"에 따라 다섯 항목으로 정리한 JSON을 만든다.
2. **Python이 검사하고 저장한다.** 만든 JSON을 표준 입력으로 `scripts/save_memo.py`에 넘긴다.
   JSON을 파일로 먼저 쓰지 않는다. 명령 한 번으로 검사와 저장을 끝낸다.
   스크립트는 스키마를 검사하고, 통과하면 `outbox/`에 저장한다. 항목 누락·추가나
   자료형 오류가 있으면 **저장하지 않고** 무엇이 틀렸는지 알려 준다.

```bash
python3 skills/memo-to-json/scripts/save_memo.py --out outbox/메모.json <<'JSON'
{"메모 날짜": "2026-09-16", "끝낸 일": ["..."], "남은 일": ["..."], "변경한 내용": ["..."], "확인할 질문": []}
JSON

# 저장 전 검사만
python3 skills/memo-to-json/scripts/save_memo.py --check-only <<'JSON'
{ ... }
JSON
```

- 종료 코드 `0` = 검사 통과(저장 또는 검사만), `1` = 검사 실패(저장 안 함),
  `2` = 입력 오류(JSON 파싱 실패, 파일 없음 등).
- 검사 실패 시 출력된 오류 목록을 사용자에게 그대로 전하고, 사진을 다시 읽어
  JSON을 고친 뒤 재실행한다.
- 명령을 실행하기 전에 플랫폼이 사용자에게 허락을 물을 수 있다. 거절되면 만든 JSON을 답에 보여 주고 끝낸다.

스크립트 위치: `skills/memo-to-json/scripts/save_memo.py`
