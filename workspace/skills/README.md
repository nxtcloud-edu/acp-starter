# 스킬

이 폴더의 하위 폴더 하나가 스킬 하나다. 플랫폼은 대화를 시작할 때 `*/SKILL.md`의 머리말을 읽어 스킬 목록을 에이전트에게 알린다. 에이전트마다 쓸 스킬은 에이전트 파일(`custom/agents/<이름>.md`)의 `skills`로 고른다. 에이전트는 요청이 스킬에 맞으면 그 `SKILL.md`를 읽고 절차를 따른다.

스킬은 엔진의 스킬 기능(Claude의 스킬, Codex의 스킬)이 아니라 플랫폼이 알린다. 그래서 어느 엔진으로 돌려도 같은 스킬을 쓴다.

| 스킬 | 하는 일 | 처음 들어 있는 까닭 |
|---|---|---|
| `memo-to-json` | 손글씨 메모 사진을 읽어 정해진 다섯 항목의 JSON으로 저장한다 | AI가 읽고, Python이 검사하고 저장한다 |
| `data-to-html` | 여러 md·csv를 요약해 HTML 리포트를 만든다 | AI가 요약하고, Python이 검사하고 조립한다 |

두 스킬 모두 마지막에 Python 스크립트를 실행한다. 안전 모드에서는 이때 허락 카드가 뜬다. 에이전트가 도구를 고르고, 플랫폼이 허락을 묻고, 사람이 정하는 흐름을 여기서 본다.

## 스킬을 더하는 법

1. `skills/<스킬 이름>/SKILL.md`를 만든다.
2. 첫머리에 머리말을 적는다. `name`과 `description`은 에이전트에게 가고, `example`은 화면의 "해 보기" 버튼이 입력칸에 넣는 요청이다.

```
---
name: deadline-table
description: 안내문과 메모에서 마감을 찾아 날짜순 표로 만든다.
example: 자료/ 폴더에서 마감을 찾아 표로 정리해 줘
---

# 마감 표 만들기
(절차를 적는다)
```

3. 계산이나 검사처럼 매번 같아야 하는 일은 `scripts/`에 코드로 둔다. 스크립트의 경로는 작업 폴더(`workspace/`) 기준으로 적는다.
4. 대시보드에서 "연결"을 다시 누르면 새 스킬 목록이 간다.

Kiro Crew에서 비슷한 곳: `src/kiro_crew/skills.py`, `src/kiro_crew/skills_selection.py`(대화마다 어떤 스킬을 알릴지 고른다)
