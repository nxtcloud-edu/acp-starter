# 최종 과제: 내 에이전트 플랫폼

이 폴더에서 **내가 쓰고 싶은 에이전트 플랫폼 앱**을 만들고 발표합니다.

처음 받은 앱은 엔진(Claude, Codex, Kiro)과 대화하고, 도구를 쓸 때 허락을 묻는 데까지만 되어 있습니다. 여기에 이름을 붙이고, 내 색감으로 꾸미고, 내 일에 필요한 기능을 하나씩 붙여 갑니다. 무엇을 만들지는 자유입니다. Kiro Crew를 써 보며 아쉬웠던 것, 있었으면 했던 것에서 시작해도 좋습니다.

코드는 혼자 다 읽고 고치지 않습니다. 내 코딩 에이전트와 함께 만듭니다. 방법은 [코딩_에이전트와_일하기.md](코딩_에이전트와_일하기.md)에, 더할 수 있는 기능은 [만들_곳.md](../만들_곳.md)에 있습니다.

## 시작

1. `python dashboard.py`로 앱을 켜고, 엔진 하나에 로그인해서 대화해 봅니다.
2. 앱 이름을 정하고 내 색감으로 꾸밉니다.
3. 써 보면서 "이게 있으면 좋겠다" 싶은 기능을 하나 더합니다. 그다음 또 하나.

## 남길 것

| 곳 | 남길 것 |
|---|---|
| `계획/계획서.md` | 어떤 앱을 만들고 싶은지. 만들다 바뀌어도 괜찮습니다 |
| `기록/일지/` | 작업한 날마다 파일 하나(`_틀.md`를 복사). 맡긴 것, 내가 고른 것, 확인한 것 |
| `기록/변경.md` | 써 보며 틀리거나 불편해서 고친 것 |
| `발표/` | 발표 자료와 시연 캡처 |
| 코드 | 작업한 날마다 일지와 함께 커밋하고 푸시합니다 |

기록은 코딩 에이전트에게 정리를 맡겨도 됩니다. 마감은 수업에서 알립니다.

## 발표에서 이야기할 것

| 순서 | 내용 |
|---|---|
| 1. 내 앱 | 이름, 누가 어떤 일에 쓰는 앱인가 |
| 2. 시연 | 내 일로 실제로 써 보기 |
| 3. 만든 것 | 처음 받은 앱에서 무엇을 더하고 바꿨는가. 왜 그 기능이 필요했는가 |
| 4. 함께 만든 과정 | 코딩 에이전트에게 맡긴 것과 내가 판단한 순간 |
| 5. 돌아보기 | 다시 한다면 다르게 할 것, 더 만들고 싶은 것 |

다 만들지 못한 것도 계획과 기록으로 설명하면 됩니다.

## 지킬 것

- 안전 모드와 샌드박스 설정은 끄지 않습니다. 허락을 넓히려면 `custom/rules.py`로 합니다.
- `.homes/`(로그인 정보)와 `.env`(시크릿)는 커밋하지 않습니다. 둘 다 `.gitignore`에 들어 있습니다.
- 레포에 개인 정보와 회사 자료를 넣지 않습니다.
- 남의 코드를 그대로 가져오면 출처와 라이선스를 남깁니다.
