# YYYY-MM-DD

작업한 날마다 이 파일을 복사해 `YYYY-MM-DD.md`로 만듭니다. 코딩 에이전트에게 "오늘 한 일을 일지에 정리해 줘"라고 맡겨도 됩니다. 맡긴 것과 내가 판단한 것을 나눠 두면 발표 때 이야기하기 쉽습니다.

| 칸 | 내용 |
|---|---|
| 오늘 하려던 것 | |
| 맡긴 것 (코딩 에이전트에게 한 말) | |
| 결과 | |
| 내가 판단한 것 | 고른 것, 거절한 것, 그 까닭 |
| 확인 | 실행해서 본 것 |
| 고친 것 (변경 번호) | |
| 커밋 | |

예:

> 맡긴 것: "앱 이름을 바꾸고 차분한 초록색으로 꾸며 줘" · 결과: `brand.json`과 `style.css`의 색 토큰이 바뀌었다 · 내가 판단한 것: 에이전트가 다크 화면도 초록으로 하자고 했지만, 다크는 회색 바탕에 초록 강조만 두기로 했다 · 확인: 새로 고침해서 라이트와 다크를 모두 봤다 · 커밋: (커밋 주소)
